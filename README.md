# moneo

A privacy-first personal finance web app built with plain HTML, CSS, and JavaScript.

## Run locally

From this directory, start a static web server:

```powershell
python -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000) in a browser.

The app stores transactions, accounts, and budgets in the browser's local storage. It does not include server-side accounts, authentication, or bank connections.
